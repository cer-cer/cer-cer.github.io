# 资源站

用于获取分类、列表和详情

ac：模式（video list或detail详细模式），为空＝列表标准模式

ids: 影片id，多个使用,隔开

t: 类型

h：最近多少小时内

pg: 页数

wd：搜索like

at：输出格式，可选xml

list:
- http://api.fqzy.cc/api.php/provide/vod/?ac=list&t=xxx

detail:
- https://api.tiankongapi.com/api.php/provide/vod/?ac=detail&ids=xxx

search:
- https://www.feisuzyapi.com/api.php/provide/vod/?wd=美女&t=xxx
